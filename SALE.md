# RAZE OS Home — Complete Project Acquisition

## Asking Price

**US$12,500**

The asking price is for the complete project acquisition described below.

---

## What Is Being Sold?

The buyer receives the **complete RAZE OS Home software project**, including the production source code and the accumulated implementation developed for the real household environment.

The project is not being offered as a template, UI kit or partial prototype.

The intended transaction is an **exclusive project transfer**.

After the transfer, the buyer may:

- use the source code
- modify it
- rebrand it
- integrate new hardware
- commercialize it
- sell it
- redistribute the resulting product
- build a new product from the acquired code

The seller does not intend to retain a continuing ownership claim or reuse the sold project after an exclusive transfer.

Final legal ownership and transfer terms are established in the purchase agreement.

## Why US$12,500?

The value is not based on the number of screens in the UI.

The project represents roughly **600 source/project files**, approximately **48 physical devices** in its real household environment, months of iterative development and a large amount of integration and debugging work across Android, IoT, cameras, security, automation, reasoning and learning.

The buyer is purchasing an existing foundation instead of starting with an empty Android project and recreating the same interconnected systems.

The simplest version of the argument is:

> **You can build your own smart home operating system. The expensive part is making all the wires talk to each other. This one already does.**

## Transfer Philosophy

This is intended to be a clean handover, not an ongoing consulting arrangement by default.

The buyer acquires the project so they can take ownership of the codebase, change its identity and continue development independently.

Any post-sale support, migration assistance or consulting is a separate matter and is not assumed by this listing unless explicitly agreed in writing.
