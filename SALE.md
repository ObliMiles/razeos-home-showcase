## Why Acquire Instead of Building From Scratch?

Building a system of this type requires considerably more than creating a dashboard.

The project already contains an integrated architecture covering device state, household context, reasoning, action execution, verification, persistence, learning, feedback, and kiosk presentation.

Acquiring the project can provide a starting point for further product development without rebuilding the complete foundation.
