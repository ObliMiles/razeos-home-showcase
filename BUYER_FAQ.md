# Buyer FAQ

## What exactly is being sold?

The complete RAZE OS Home project and production source code as an exclusive acquisition, subject to the final purchase agreement.

The intended transfer is not a shared non-exclusive license. The buyer may rebrand, modify, commercialize, redistribute and resell the resulting product. Final IP assignment and transfer language is established contractually.

## Is the source code included?

Yes. The sale is for the complete project, including the production Android source code and the existing project architecture, integrations, UI, reasoning/learning implementation and supporting project material.

## Is the public repository the source code?

No. This repository is a showcase and technical due-diligence package. It intentionally excludes the production source tree, credentials, signing keys and private configuration.

## Has the system actually been used?

Yes. It was developed for and operated in the developer's own household rather than being created only as a demo or prototype.

## How large is the project?

The production project contains roughly 600 source/project files. The current household environment contains approximately 48 physical devices across the integrated ecosystem.

## What integrations are currently demonstrated?

eWeLink, Sonoff devices, cameras/RTSP workflows, human and presence detection, Telegram, Xiaomi, Dreame, voice-assistant functionality, security workflows, occupancy/room awareness, automation, autonomous reasoning, verification and household learning.

## Does autonomous reasoning actually control devices?

The current implementation has reached the reasoning + real action + verification + learning stage. Reasoning can participate in supported device actions through the existing action infrastructure, with verification and feedback paths around the resulting behavior.

## Does the system learn from users?

Yes. Reasoning decisions can be marked correct or incorrect. Incorrect decisions can receive natural-language feedback, which is processed into structured, narrow-scope decision knowledge that can be consulted by future reasoning.

## Does learning override sensor truth?

No. The knowledge layer is intended to influence decision context rather than rewrite deterministic physical-world truth.

## Can the buyer put their own brand on it?

Yes. The intended exclusive transfer permits rebranding and modification. The buyer can adapt the UI, product identity, integrations and commercial strategy to their own product.

## Was it previously sold or commercially distributed?

No. The project was developed for personal household use and has not previously been commercially distributed, licensed or sold to another party.

## Are there existing customers or revenue?

No claims are made about customers, revenue or market adoption. The value is the existing engineering work, source code, architecture, integrations and real-world operating foundation.

## Why is the asking price US$12,500?

The price reflects the accumulated engineering work and the breadth of the existing system: Android kiosk infrastructure, IoT integrations, camera and security workflows, room context, automation, reasoning, action execution, verification, learning and feedback across a project of roughly 600 files.

## Can the buyer inspect the source before purchase?

A serious buyer can request a private technical due-diligence process. The exact level and method of source access is agreed before transfer so that both parties can evaluate the project without publicly exposing the production code.
