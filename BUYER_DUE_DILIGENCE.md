# Buyer Due Diligence

RAZE OS Home is offered as a complete existing software project. This document exists so a serious buyer can evaluate it without relying on marketing language alone.

## What the Buyer Is Evaluating

The public repository provides:

- architecture documentation
- feature documentation
- integration overview
- real-world scenarios
- UI screenshots
- presentation deck
- data and knowledge model
- acquisition terms

The production source code is not included in this public showcase repository.

## Recommended Evaluation Questions

A buyer should verify:

1. Which Android device will be used as the target kiosk?
2. Which existing integrations are relevant to the buyer's hardware?
3. Which external APIs/accounts are required?
4. Which hardware-dependent features require the buyer's own devices?
5. Which credentials must be replaced during deployment?
6. What Android SDK/build environment is required?
7. Which integrations are local and which depend on third-party services?
8. Which application branding and configuration must be changed after transfer?

## Demonstration Scope

A serious acquisition can be evaluated around the actual workflows documented in `REAL_WORLD_SCENARIOS.md`, including security notification, contextual automation, room/device reasoning, Dreame scheduling, overnight security context and feedback/learning.

## No Artificial Business Claims

The project has not previously been commercially distributed. There are no claimed customers, revenue figures, market-share figures or fabricated deployment statistics.

The value proposition is the existing engineering work, architecture, integrations, working household workflows and transferable source code.

## Important Technical Boundary

The project is a real personal smart-home system, not a promise that every arbitrary smart-home device will work without adaptation. The buyer is acquiring the implemented foundation and can extend it for their own hardware and product requirements.

## Transfer

The intended transaction is an exclusive project transfer. The buyer is intended to receive the complete production source code and project materials and to be free to rebrand, modify and commercialize the result. Final legal terms are determined by the purchase agreement.
