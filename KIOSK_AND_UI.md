# Kiosk and User Interface

Raze OS Home is designed for dedicated Android kiosk hardware.

## Persistent Interface

The application is intended to remain available as a household dashboard rather than behaving like a conventional mobile application.

---

## Main Navigation

The current interface contains dedicated pages for major household functions:

- eWeLink
- Camera
- Xiaomi
- Dreame
- Finance / household tracking
- Household Learning
- Telegram Archive
- Autonomous Reasoning

---

## Household Learning

The Household Learning page combines existing household learning information with autonomous reasoning events.

Reasoning cards can display:

- action
- explanation
- evidence
- confidence
- verification result
- feedback controls

---

## Feedback

The user can review an autonomous decision and provide feedback without interrupting the autonomous execution process itself.

The feedback interface is presented when the user chooses to review or challenge a decision.

---

## Screen Protection

The application is designed for long-running kiosk operation and includes screen protection behavior appropriate for an unattended wall-mounted display.
